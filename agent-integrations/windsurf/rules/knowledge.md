# Windsurf Cascade .knowledge bridge

Use `.knowledge/maintenance/routing_bundle.json` as the first routing artifact for the current task.

When a repository-root `AGENTS.md` contains the `.knowledge` managed block, treat it as the shared cross-agent contract. This Windsurf rule is only the Cascade-specific bridge; do not duplicate or override the shared instructions.

Use `.knowledge/Quick-Start.md` for the current workflow and `.knowledge/agent-integrations/_shared/metrics-reporting.md` for final reporting. Never describe the deterministic local context estimate as provider-reported model-token usage.

For concurrent work, set a stable `KNOWLEDGE_AGENT_ID` and use a separate worktree or branch.
