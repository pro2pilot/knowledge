# FAQ

## What is `.knowledge`?

`.knowledge` is a repo-local routing, evidence, trust, freshness, repair and PR-review system for coding agents.

## Is it an AI coding agent?

No. It does not replace Claude, Codex, Cursor, OpenCode, Cline or other agents.

## Does free `.knowledge` require cloud or login?

No. Free Core and Free Inspector are local-first and work without cloud, login or telemetry.

## What is Pro?

Pro unlocks deeper workflows inside the same Inspector: PR Impact Pro, Repair Planner, Trust History, Policy Packs, Team Dashboards, Memory Governance and Audit History.

## Can agents auto-merge?

Not by default. Merge policy defaults to Manual Only and source-code changes require human review.
