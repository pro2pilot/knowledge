# .knowledge Product Canon

`.knowledge: repo-local trust layer for coding agents.`

It is a repo-local routing, evidence, trust, freshness, repair and PR-review system for coding agents.

It is not an agent orchestrator, AI IDE, memory app, generic workflow canvas or auto-merge bot. Agents execute work; `.knowledge` records, verifies, routes, repairs, queues, locks, reviews and reports the knowledge state around that work.

External memory is advisory only. Code, tests and evidence outrank modules, decisions, wiki, sessions and memory.
