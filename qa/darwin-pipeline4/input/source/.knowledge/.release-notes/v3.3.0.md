# v3.3.0 - Safer local knowledge maintenance and task-scoped routing

v3.3.0 upgrades the public v3.2.11 release directly to a more evidence-aware
local `.knowledge` workflow.

## What changed

- Agent integrations now coexist safely: Codex, OpenClaw, Hermes, and Devin share one runtime-neutral `AGENTS.md` managed block, while Devin and Windsurf use separate `.devin/rules/knowledge.rules` and `.windsurf/rules/knowledge.md` files.
- Finding-specific repair and Repair-on-touch keep maintenance bounded to the
  active task, preserve verified work, and leave unrelated debt visible.
- Global Doctor health and task readiness are reported separately so an agent
  can distinguish repository-wide maintenance from the safety of the current
  task.
- Task-scoped routing selects the relevant first-read context and reports one
  clear local estimate state: narrowing, overhead, neutral, or unavailable/not
  comparable. This is a deterministic local context estimate, not
  provider-reported model-token usage.
- Field Report keeps collection, translation, approval, redaction, and optional
  publication state separate. Publication-ready output is always English and
  includes a report-type disclosure, filtered repository profile, explained
  outcome table, metric interpretation, and internal-organization
  generalization. Non-English translation is bound to an exact privacy-stable
  export.
- Install, update, and release checks preserve curated user knowledge while
  keeping generated state and maintainer material outside installed runtime
  files.
- Installed agent integrations use the same four-state local-context reporting contract and do not describe estimates as provider-reported model-token savings.
- Maintainer release workflows and comparative benchmark harnesses remain in the source/evidence layer rather than the installed runtime.

## Upgrade

Upgrade directly from **3.2.11 to 3.3.0**. Run the normal local install or
update checks after extraction; they verify the installed runtime before use.
When the 3.2.11 updater performs the hand-off, the new verifier completes the
removal of retired source-only benchmark and integration material only after
that updater has written its rollback backup. Fresh 3.3.0 installs never
contain that source-only material.

## Verification scope

The release includes focused approval, redaction, translation, publication
state, routing, repair, and update-safety regression coverage. It does not make
comparative speed, accuracy, error-rate, or model-token-savings claims.
