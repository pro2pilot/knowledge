# kb-audit

Audit `.knowledge` before planning or editing.

Read first:

1. `.knowledge/maintenance/routing_bundle.json`
2. `.knowledge/maintenance/trust_report.json`
3. `.knowledge/maintenance/handoff_summary.json`
4. `.knowledge/maintenance/quality_report.json`
5. Relevant `.knowledge/modules/*.json`

Check freshness, contradictions, evidence coverage, test linkage, and quality issues before trusting summaries.

If anything is `suspect`, `needs_recheck`, `low_confidence`, `advisory_only`, or `routing_trusted`, re-read the relevant source files before behavior claims.
