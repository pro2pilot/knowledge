# v3.4.0-rc1 - Integrated task routing and evidence reuse

- Adds `agent-task begin` as the default meaningful-task entrypoint. It returns
  the exact canonical task first-read body before broad exploration.
- Adds `agent-task finish`, which executes primary verification once and may
  reuse the resulting native KVE IDs for one exact safe scoped KVR/apply.
- Adds durable, lock-serialized phase recovery and idempotent completion.
- Separates primary outcome, routing, Doctor, Task Readiness, native repair,
  deferred debt and provider usage in the final result.
- Updates Codex, Claude and OpenCode task integrations.
- Removes the heuristic token-saving estimate from `agent-footer`; only
  canonical task-routing state may be rendered.
- Runs an optional release flow before repair planning, so newly detected
  overlapping debt blocks a false trust elevation instead of being hidden by
  an earlier receipt.
- Revalidates final lifecycle closure before reporting a repair as applied;
  unsustained recertification remains open and visible.
- Preserves a verified primary task result when an optional release-flow phase
  returns a structured failure, reporting `completed_with_warnings` instead of
  losing the task evidence.
- Team-mode task workflows keep repair policy flags separate from team context and emit only safe relative state diagnostics.
- Adds a content-addressed first-read acknowledgement receipt so the final
  result is physically bound to the exact begin-time task snapshot.
- Restricts finish request files and physical test working directories to the
  repository boundary; symlink, junction, hardlink and path-escape inputs fail
  closed.
- Makes official ZIP packaging independent of source file mtimes and supports
  exact SemVer prerelease artifact names and allowlisted prerelease notes.
