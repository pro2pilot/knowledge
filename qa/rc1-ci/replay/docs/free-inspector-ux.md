# Free Inspector UX

Launch:

```bash
node .knowledge/inspector.js
```

The Inspector starts a local `127.0.0.1` server, creates a session token, serves the UI, exposes allowlisted local actions and writes action logs locally.

Canonical navigation:

```txt
Home
Review
Knowledge Trust
Agents Activity
Reports
Settings
Pro Preview
```

There are no top-level `Metrics`, `Command Center`, `Work` or chat tabs. Metrics are cards. Actions are contextual buttons and a global action drawer. Static HTML remains a read-only/copy-command fallback.
