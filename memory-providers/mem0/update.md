# Mem0 OSS Update Preview

Updates are explicit and pinned.

```bash
node .knowledge/tools/memory-provider.js update mem0-oss --to mem0ai==<reviewed-version> --yes-i-reviewed-license --json
```

This records an update receipt only. Review Mem0 release notes, license, and package provenance before running a package manager manually.

Status/report commands stay offline and do not check PyPI automatically.
