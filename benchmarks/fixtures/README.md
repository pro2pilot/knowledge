# Benchmark Fixtures

The current harness uses deterministic local fixtures generated by the source self-tests:

- PR Impact temp git fixtures from `tools/self-test-pr-impact.js`;
- Team Mode worktree fixtures from `tools/self-test-team-inspector-json.js`;
- memory provider dry-run/test adapter fixtures from `tools/self-test-memory-providers.js`;
- current source reports for routing, trust/freshness, repair queue, search and privacy checks.

Large public fixture repositories are planned for future runs. Claims based only on generated fixtures must use the `measured-on-fixture` status.
