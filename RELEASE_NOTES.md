# v3.1.8 — First public release

`.knowledge` is an open local control plane for AI coding agents.

## Highlights

- One first-read routing bundle
- Trust and freshness status
- Repair queue
- Local search scopes
- Visual Inspector
- Cookbook flows
- Official templates
- Secret scan baseline
- Pinecone Local / Pinecone Cloud bridge, disabled by default
- Codex, Claude Code, OpenCode integrations
- Optional advisory update checks, disabled by default
- Apache-2.0 core

## Try it

Download `.knowledge.zip`, extract it into a repository root, then tell your agent:

```txt
Read `.knowledge/Quick-Start.md` and execute it for this repository.
```

Or clone this repository into a project as `.knowledge`:

```bash
git clone https://github.com/pro2pilot/knowledge.git .knowledge
```

## Notes

Metrics are order-of-magnitude and based on a synthetic SaaS-shape fixture. Tiny repositories may show overhead because the routing bundle has fixed structure cost.
